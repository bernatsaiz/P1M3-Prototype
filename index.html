About the data

… records returned by the Smithsonian Open Access API for the search term “miscellaneous”. Places are matched to countries by name (including U.S. states); an object that names several countries counts once in each. Map rates divide by each country’s objects in the whole Smithsonian Open Access collection (built by build-country-totals.js). Types use the first listed object type. Dates use the earliest decade listed.
